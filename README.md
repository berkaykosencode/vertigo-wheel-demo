# Vertigo Wheel Demo

Work-in-progress Unity internship demo featuring a wheel-based reward game.

**Unity version:** 6000.3.23f1

**Implemented**

- Eight-slot wheel animation using DOTween.
- Editor-configurable rewards and wheel contents using ScriptableObjects.
- Gold and cash accumulation during a session.
- Bomb results that clear accumulated rewards and end the session.
- Result display, reward totals, and session restart.

**Remaining work**

- Zone progression and increasing rewards.
- Bomb-free silver wheels at every fifth zone.
- Special bomb-free golden wheels at every thirtieth zone.
- Collecting rewards and leaving at eligible zones.
- UI polish and verification at 20:9, 16:9, and 4:3 aspect ratios.
- Android APK release, gameplay video, and screenshots.

**Running the prototype**

1. Open the project through Unity Hub using Unity 6000.3.23f1.
2. Open `Assets/Scenes/WheelDemo.unity`.
3. Enter Play mode.

The current version is a development prototype; the final Android release is pending.
